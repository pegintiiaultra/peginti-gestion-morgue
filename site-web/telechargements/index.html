Télécharger un logiciel PEGINTI.

Téléchargez le fichier, vérifiez son empreinte si vous le souhaitez, puis suivez « Comment l'installer ».

Vérifier un fichier : sur Windows, certutil -hashfile fichier.zip SHA256 ; sur Android (Termux) ou Linux, sha256sum fichier.zip. Le résultat doit être identique à l'empreinte affichée.
